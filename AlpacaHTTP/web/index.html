iOptron iMate PowerBox Configuration

Controls the iMate's on-board DC power ports over local GPIO. Exposes three switches: DC3 (always-on pass-through, read-only), DC1 and DC2 (switchable). Run AlpacaBridge on the iMate itself.

Optional. Defaults to /dev/gpiochip1 (the iMate's main GPIO bank on the OpenAstro mainline kernel).
Software PWM frequency for any DC port marked PWM below. 50 Hz dims flat panels (their LED driver cycles fully each period); ~1 kHz is smoothed into on/off by a panel but is fine for dew heaters.

DC Power Ports

Tick PWM on DC1/DC2 for dimmable loads — dew heaters and flat panels (exposes a 0–100% slider in clients like NINA); leave it unticked for plain on/off. A flat panel needs a low frequency (~50 Hz) to dim, set above. Cameras, mounts, and other regulated gear should stay on/off. DC3 is a hardwired always-on pass-through.
DC port GPIO line PWM
DC1 118 (PD22)
DC2 114 (PD18)
