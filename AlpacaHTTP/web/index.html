Software PWM frequency for any DC port marked PWM below. 50 Hz dims flat panels (their LED driver cycles fully each period); ~1 kHz is smoothed into on/off by a panel but is fine for dew heaters.

DC Power Ports

Tick PWM on DC1/DC2 for dimmable loads — dew heaters and flat panels (exposes a 0–100% slider in clients like NINA); leave it unticked for plain on/off.
