# Release-prune cases: <released tag> | <existing release tags> | <tags to delete>
# ('-' is an empty list). scripts/release_prune.py --self-test reads this file;
# the release.yml prune job and scripts/ci_preflight.sh run that self-test. A
# '#' starts a comment.
# beta N > 1 deletes the older betas of the same X.Y.Z and keeps beta N.
v5.0.0-beta.3 | v5.0.0-beta.1 v5.0.0-beta.2 v5.0.0-beta.3 | v5.0.0-beta.1 v5.0.0-beta.2
# Numeric, not text, order; output oldest first whatever the input order.
v5.0.0-beta.10 | v5.0.0-beta.10 v5.0.0-beta.9 v5.0.0-beta.2 v5.0.0-beta.1 | v5.0.0-beta.1 v5.0.0-beta.2 v5.0.0-beta.9
# beta.1 supersedes nothing.
v5.0.0-beta.1 | v5.0.0-beta.1 | -
# A newer beta is never deleted by an older release (a re-run of an old tag).
v5.0.0-beta.2 | v5.0.0-beta.1 v5.0.0-beta.2 v5.0.0-beta.3 | v5.0.0-beta.1
# stable deletes every beta of its X.Y.Z.
v5.0.0 | v5.0.0 v5.0.0-beta.1 v5.0.0-beta.2 v5.0.0-beta.10 | v5.0.0-beta.1 v5.0.0-beta.2 v5.0.0-beta.10
# stable with no betas.
v5.0.0 | v5.0.0 v4.2.0 | -
# Betas of another X.Y.Z are left alone.
v5.0.0-beta.2 | v5.0.0-beta.1 v5.0.0-beta.2 v5.1.0-beta.1 v4.9.0-beta.1 | v5.0.0-beta.1
v5.0.0 | v5.0.0-beta.1 v5.1.0-beta.1 v5.0.1-beta.1 v15.0.0-beta.1 | v5.0.0-beta.1
# nightly-build and stable tags are left alone.
v5.0.0-beta.2 | nightly-build v4.2.0 v5.0.0 v5.0.0-beta.1 v5.0.0-beta.2 | v5.0.0-beta.1
v5.0.0 | nightly-build v4.2.0 v5.0.0-beta.1 | v5.0.0-beta.1
# Malformed or unrelated names are ignored.
v5.0.0-beta.3 | v5.0.0-beta.0 v5.0.0-beta.01 v5.0.0-beta v5.0.0-rc.1 v5.0.0-beta.1-x 5.0.0-beta.1 v5.0.0~beta1 v5.0.0-beta.1 | v5.0.0-beta.1
