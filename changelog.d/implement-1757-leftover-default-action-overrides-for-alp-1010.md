### Changed

- **remotealpaca ObservingConditions Action error names the action**, remotealpaca driver, issue #1757. The driver's own six Action and Command overrides are gone and it uses the `AlpacaDriver` not-implemented defaults, so an Action call it does not support now answers `Action not supported: <name>` (still 0x40C) instead of `Action not supported`; Command* still answer 0x400. The OnStep focuser's copy, identical to the default, is removed too. The text comes from `AlpacaDriver::action` in `AlpacaCore/include/alpacacore/alpacadriver.h`; the codes (0x40C, 0x400) are asserted by the `onstep_focuser` and `remotealpaca_observingconditions` entries of the contract sweep (`AlpacaCore/tests/test_contract_sweep.cpp`, `case_unsupported_action`) and by `AlpacaCore/tests/test_remotealpaca_observingconditions.cpp:302`.
