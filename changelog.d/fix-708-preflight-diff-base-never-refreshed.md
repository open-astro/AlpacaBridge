### Fixed
- **Pre-flight refreshes its diff base from the remote the base names** (tooling, issue #708). `scripts/ci_preflight.sh` fetched `origin` with the base's prefix kept, so the default `main` was never updated and `PREFLIGHT_BASE=upstream/main` failed with exit 128 behind `|| true`. It now fetches `<remote> <branch>` when the base is `<remote>/<branch>`, prints a `WARNING:` with the cached ref's commit date when the fetch fails, and warns once when the base is a local branch that is not refreshed.
