### Changed
- **StellaVita switch driver reaches the power box through an injectable interface** (AlpacaCore, issue #1326): `TouptekPowerboxSDK` (`touptek_powerbox_sdk.h`) is implemented by the existing `TouptekPowerboxWrapper`, and `create_touptek_switch` gains an overload taking it. The two-argument factory still builds the real wrapper, so runtime behaviour is unchanged: ports still start on and connecting writes nothing (`ToupTek powerbox seam - connecting leaves every port on and writes nothing`), and the Cypress hub lines stay unexposed. `port_config()` now returns by value. A scripted `FakeTouptekPowerboxSDK` and a `LockedTouptekPowerboxSDK` decorator back new cases in `test_touptek_powerbox_seam.cpp`, a connected `[stress]` case and a tier-2 row in the contract sweep. ConformU was not re-run.
