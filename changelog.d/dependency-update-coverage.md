### Added (tooling)
- **Update checks for every vendored SDK and the upstream protocol documents** (`scripts/dependency_updates.py`, `scripts/dependency_sdk_versions.json`): the ten SDKs now each have an automatic source (ZWO's SDK JSON endpoint; the QHY changelog; the SVBONY, ToupTek and Player One download pages; libgpiod), so none is left as a manual check, and a new `documents` list watches 21 upstream references against a reviewed baseline: the SkyWatcher, SynScan and iOptron protocol PDFs, the Bisque and Losmandy reference pages, Wanderer's dated protocol PDFs, the Gemini and Oasis ASCOM installers their protocols were recovered from, the eight INDI driver files the iOptron, Wanderer, Celestron, ZWO AM and OnStep drivers were derived from, and the ConformU beta tarball. A changed document opens one issue (`dependencies`, `documentation`, `P4`) that closes when a pull request sets its baseline to the new value. `--pin` keeps every top-level section of the table (it used to drop any key it did not name) and `--check` fails when a document's local copy is missing.
- **Coverage gate for new vendors, SDKs, protocol folders and pinned tools** (`scripts/dependency_snapshot.py --check`, the `docs-drift` job): fails on an SDK without an `updates` block, a docs-only directory with no watched document and no `no_upstream` reason, a directory under `AlpacaCore/src/vendors/` missing from the new `vendors` map (each vendor maps to the SDKs and documents it is built from, or states why it has no upstream), a `no_upstream` exemption for a directory that is no longer docs-only, and a workflow `ver=` pin the snapshot does not read. A dropped connection or a timeout during the weekly check is a broken source for that entry, not an aborted run; pages time out after 30 s, hashed documents after 300 s, and the job bound is 30 minutes.
