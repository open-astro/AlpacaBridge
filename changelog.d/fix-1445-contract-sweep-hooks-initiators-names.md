### Changed

- **Contract sweep: firmware and SDK hooks, telescope asynchronous initiators, filter wheel names**, tests only, issue #1445. Tier 2 now checks on every host that `get_device_firmware()` and `get_device_sdk_version()` return within 100 ms while a connect is in flight and never throw while disconnected; on telescope hosts that `MoveAxis(axis, 0)` and `Park` return without throwing in under 1 s (a host whose fake cannot answer states why in `park_unavailable` or `move_axis_unavailable`); and tier 1 checks that every filter wheel name is non-empty and that a names write and an offsets write are accepted and read back while disconnected. Covered by `AlpacaCore/tests/test_contract_sweep.cpp` (`case_t2_firmware_sdk_hooks`, `case_t2_async_initiators`, `case_filterwheel_names_offsets_disconnected`).
