### Changed (tests)
- **SynScan and Celestron NexStar async tests share one fake hand controller each** (AlpacaCore tests, issue #2230): `fake_synscan_handset.h` and `fake_celestron_handset.h` replace the six local handset models in the SynScan async park, slew-failure, slot and initiator-supersede files and the Celestron async park and slew-failure files. Where the copies disagreed the shared model follows the handset (an `M` ends a GOTO at once, `t` reads back the last `T`, an RA variable-rate move replaces tracking, a GOTO lands on `r` and `b`, the DEC autoguider port answers version 1.0, `MTR_AUX_GUIDE` is acknowledged), an unmodelled hand-controller command gets no reply instead of `0#`, and the firmware, time, pier and set-time commands the cases relied on are modelled from the wrappers. GOTO landing, the starting position and Celestron tracking are constructor arguments each file states. Case names, counts and assertions are unchanged; one SynScan slot case keeps the old RA-move behaviour behind a named knob for a driver defect the shared model exposed, and one slew-failure case leaves the status poll's reads out of the command log it counts. The identical `wait_until` helper moves to `fake_mount_server.h`.
