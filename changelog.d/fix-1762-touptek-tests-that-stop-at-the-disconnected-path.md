### Changed

- **ToupTek connected-path tests**, ToupTek drivers, issue #1762. The readout-mode, offset, AAF value-range, thermal-switch camera-index and thermal-switch async cases now run over `FakeToupTekSDK` with the driver connected, so a driver that stops filling the readout list, returns 0 for `Offset`, skips the range check, accepts a bad camera index or reports async support fails them (`AlpacaCore/tests/test_touptek_camera.cpp`, `test_touptek_focuser.cpp`, `test_touptek_thermal_switch.cpp`). The shared-open reference count is now one `SharedOpenRefs` helper used by both the SDK wrapper and the test fake, with its own unit cases in `test_touptek_fake_sdk.cpp`; wrapper behaviour is unchanged. The fake AAF now throws on a read through a Set code or a write through a Get code, and the thermal-poller case runs on the fake task clock instead of sleeping, so a poller that skips its priming tick fails it every time.
