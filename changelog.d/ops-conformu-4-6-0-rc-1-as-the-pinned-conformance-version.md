### Changed (tooling)
- **ConformU standard is the 4.6.0-rc.1 pre-release (build 56430)** (`/conformu`, `/driver-build`, `conformu-fake.yml`, `SUPPORTED-DRIVERS.md`, issue #1946): `/conformu` and the fake-telescope workflow install `conformu.4.6.0.linux-arm64.tar.gz` from the ConformU v4.6.0-rc.1 GitHub release with a sha256 check. It was pinned provisionally on a board instruction, before the one-camera plus one-telescope rig check; those runs are recorded in `SUPPORTED-DRIVERS.md` afterwards. Reports made with 4.5.3 and earlier stay valid.
- **The dependency check handles a pre-release baseline** (`scripts/dependency_updates.py`, `python3 scripts/dependency_updates.py --self-test`): when the recorded baseline is a pre-release it reads the release list instead of `releases/latest`, so `conformu` at 4.6.0-rc.1 is not broken, 4.5.3 is not an update, and the final 4.6.0 is. The dependency snapshot reports `pkg:github/ASCOMInitiative/ConformU@4.6.0-rc.1` (`python3 scripts/dependency_snapshot.py --self-test`). `/conformu` step 2g lists releases the same way.
