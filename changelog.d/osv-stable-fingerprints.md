### Fixed (tooling)
- **Dismissed OSV alerts stay dismissed across Debian security updates** (`scripts/dependency_updates.py --filter-sarif`): osv-scanner's SARIF fingerprint includes the package version, so when trixie moved curl from `8.14.1-2+deb13u5` to `+deb13u7` code scanning marked every dismissed curl alert fixed and reopened it as a new one, without its dismissal reason. The filter now sets each result's fingerprint to a hash of its Debian source package and advisory ID, so one finding is one alert across Debian revisions; an alert still closes when Debian fixes the advisory. The first scan after this change reopens current findings once under the new fingerprints.
