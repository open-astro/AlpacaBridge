### Changed

- **Celestron NexStar position, status getters and `DeviceState` are served from a polled snapshot, and `TimeStamp` is when the poll measured** (Celestron, issue #1337): the 2 s position cache is gone; one status poll runs for the life of a connection (1 s, on the task clock) and RightAscension, Declination, Altitude, Azimuth, Slewing, SideOfPier, Tracking and `DeviceState` answer from its frame with no mount round trip, so a read stays under the ConformU fast-response target on a slow link (`test_celestron_telescope.cpp`, "Celestron snapshot - getters and DeviceState make no mount transaction at 100 ms per transaction"); a client write reads back at once and a poll that sampled before the write cannot undo it ("a setter's value is read back at once and a stale poll does not undo it"); a moved mount is served after the next poll, stamped when measured ("a position the mount moved is served after the next poll, stamped when measured"); past the staleness bound the link-loss policy of decision 0009 applies, and `DeviceState` is the empty list with no `TimeStamp` ("past the staleness bound DeviceState is empty with no TimeStamp"). A site written by a client while the poll reads the mount's location is no longer overwritten by the older value ("a site written during the poll's location read is not overwritten"). Slewing is refused as not available yet, not served as false, when the connect-time slewing query went unanswered ("Slewing is unknown, not false, until a query has answered"), and a tick on a dead link ends at its first failed exchange, including a failed FindHome check or location read, so a Disconnect waits for one exchange timeout ("the slow fields of a tick stop at the first failure", "a failed location read ends the tick", "a failed home-status check ends the tick"); the tick on which the third FindHome check fails first stops the mount, which can take longer on a dead link. The poll retries an unread site every 30 s, so a link whose location never reads still samples on the next full tick ("a link whose location never reads still samples on the next full tick").
