### Changed (tests)

- **One `error_code_of` test helper** (tests, issue #2488): `AlpacaCore/tests/driver_rig.h` now holds `error_code_of(fn, message = nullptr)`, which returns the Alpaca code `fn` throws and `0` when it returns, and lets any other exception propagate. Twenty-eight test files drop their local copies (the bisque pulse-guide poll keeps its own `-1` "still guiding" result), which disagreed on what "nothing threw" returns (`-1` in some, `0` in others); the assertions that expected `-1` now expect `0`. `AlpacaCore/tests/test_driver_rig.cpp` covers the three cases (an Alpaca code, no throw, another exception), and `worker_code_of` (the same for a worker thread, `-1` for a non-Alpaca exception) has its own case.
