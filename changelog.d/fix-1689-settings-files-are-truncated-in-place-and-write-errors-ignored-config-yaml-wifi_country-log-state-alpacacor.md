### Fixed
- **Wi-Fi country and three AlpacaCore stores are written atomically** (AlpacaHTTP, AlpacaCore, issue #1689): `WifiManager::set_country` now writes `wifi_country` with `write_file_atomic` instead of truncating it in place, and a failed write raises `WifiError` ("country applied but could not persist") instead of reporting success (`test_wifi_manager.cpp`, case "persist_country replaces the file atomically and reports a failed write"). The device location, flat-number and power-port boot-ID files use the same helper, which adds an fsync of the file and its directory; file formats are unchanged.
