### Added
- **Turn the Host check on or off and edit the allowed host names from the web UI**, AlpacaHTTP, issue #392. The server settings area has a "Restrict Host names (DNS-rebinding protection)" toggle and an "Allowed host names" field, so a router name such as `astropi.lan` can be allowed without SSH. They save through the existing `PUT /management/v1/description` (`HostCheckEnabled`, `AllowedHosts`; `GET` reports both and whether the environment fixes each), apply at once and are written to the `http:` section of the config file. A save that would refuse the browser's own `Host` is refused with HTTP 400 and changes nothing. A field set by `ALPACAHTTP_HOST_CHECK` or `ALPACAHTTP_ALLOWED_HOSTS` is read-only and a change to it is refused.
