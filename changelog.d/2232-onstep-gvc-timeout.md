### Fixed

- **OnStep connect no longer waits out the response timeout for `:GVC#`**, OnStep driver, issue #2232. Since #2215 the connect read the device name with `:GVC#` on every OnStepX mount, and a firmware without the command sends no reply at all, so every connect to a TeSeek HM-17 on OnStepX 10.23a took about 5 s longer (6.0 s against about 0.9 s), over serial and network alike. OnStepX added the command in `d9de0b8d` while the version still said 10.23a, and 10.23b (`6cf2e575`, minutes later) is the first release that has it. The connect now reads `:GVN#` and asks only a major above 10, 10.24 and later, and 10.23 with a patch letter after `a`; 10.23a and older releases are not asked, so the name stays `OnStep Telescope` there. Covered by `AlpacaCore/tests/test_onstep_telescope.cpp`; the name is [decision 0024](docs/decisions/0024-device-names.md).
