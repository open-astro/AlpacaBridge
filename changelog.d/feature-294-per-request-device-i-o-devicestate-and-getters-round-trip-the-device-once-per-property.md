### Changed

- **ZWO EAF focuser and CAA rotator answer `DeviceState` and the position getters from one short-lived status frame instead of one SDK round trip per property**, AlpacaCore ZWO drivers, issue #294. A refill (at most once per 100 ms, `util/ttl_status_cache.h`) reads IsMoving, Position and Temperature (EAF) or IsMoving and the angle (CAA) together; `MaxStep`, `MaxIncrement` and the CAA `Reverse` flag are read once at connect and cleared on disconnect, and a move, halt, sync or reverse change drops the frame (cases in `test_zwo_focuser.cpp` and `test_zwo_rotator.cpp`). Three consecutive failed refills latch a link fault that makes reads throw `DriverException` "communications compromised" until a read succeeds again, with no reconnect (the CAA `Reverse` getter refuses too, and the latch and its recovery are logged at ERROR and INFO). Refs #294; remaining: filter wheels + touptek_focuser, switches + weewx, astroasis_focuser, connected EAF/CAA stress registrations. The EAF driver now takes its SDK through the new `ZWOEAFSDK` interface (`zwo_eaf_sdk.h`) so it runs without the vendor library in tests. The EAF connect now needs `get_max_step` to succeed, and an EAF Temperature failure keeps the wrapper's error code (for example `NotImplemented`).

- **Player One thermal switch and ZWO dew heater switch answer `DeviceState` and the value getters from one short-lived status frame instead of two SDK reads per switch**, AlpacaCore Player One and ZWO drivers, issue #294. A refill (at most once per 100 ms, `util/ttl_status_cache.h`) reads every element together, `SetSwitch`/`SetSwitchValue` and connect/disconnect drop the frame, and three failed refills latch the same "communications compromised" fault that clears on the next good read; names, ranges and `CanWrite` were already read at connect and cost no SDK read (cases in `test_playerone_switch.cpp` and `test_zwo_switch.cpp`). Each driver takes its SDK through a driver-local interface (`PlayerOneThermalSdk`, `ZWODewHeaterSdk`) so it runs without the vendor library in tests. The iOptron, ToupTek and ZWO ASIAIR switches and the WeeWX driver already served reads from memory and are unchanged. Refs #294; remaining: filter wheels + touptek_focuser, astroasis_focuser, connected EAF/CAA stress registrations.
