### Changed (tooling)
- **Changelog fragments put each bullet on one line, and `--check` enforces it** (`changelog.d/README.md`, `scripts/changelog_fragments.py`): the README example bullet was wrapped while most fragments and every released `CHANGELOG.md` entry keep a bullet on one line, so two fragments since v4.2.0 wrapped at about 95 columns. The Body section now states the rule and its example is on one line. `--check` (run by the `docs-drift` job and pre-flight) refuses a line that continues a bullet's text, with `a bullet is wrapped onto a second line, put it on one line`; a nested `- ` bullet, a fenced code block and a paragraph after a blank line are still accepted. The two wrapped fragments (`fix-785-synscan-precise-ra-az-decode.md`, `skywatcher-serial-settle-blocking-read.md`) are joined onto one line per bullet with the same words. Rendered Markdown and the generated `debian/changelog` do not change.
