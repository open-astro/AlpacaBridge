### Changed
- **SVBONY camera driver reaches the SDK through an injectable interface** (AlpacaCore, issue #1010): `SVBSDK` (`svbony_sdk.h`) is implemented by the existing `SVBSDKWrapper` singleton, and `create_svbony_camera` gains an overload taking it. The two-argument factory still passes the real wrapper, so runtime behaviour is unchanged. A scripted `FakeSVBSDK` and a `LockedSVBSDK` decorator back new fake-SDK cases in `test_svbony_camera.cpp`, the SVBONY `[stress]` registration (now past the connect-failure path) and a tier-2 row in the contract sweep. ConformU was not re-run. The SVBONY SDK enums now carry an explicit `std::uint8_t` underlying type.
