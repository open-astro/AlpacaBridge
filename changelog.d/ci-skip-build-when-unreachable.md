### Changed (CI)

- **A pull request whose files cannot reach the build skips the build and test jobs** (CI, issue #2780): a new `build-reach` job in `ci.yml` runs `scripts/ci_build_reach.py` over the changed files. When every file is docs, a changelog fragment, Markdown, an instruction file, a gate script, a workflow other than `ci.yml` or a committed ConformU report, `build-test`, the three all-vendors shards, `build-vendors` and `sanitizers` skip (about 39 runner-minutes for each push on #2777). The merge queue and pushes always build, and the four jobs run when `build-reach` fails. A new `build-not-needed` job passes on such a pull request, and the review bot's CI wait accepts the skipped jobs only when it did.
