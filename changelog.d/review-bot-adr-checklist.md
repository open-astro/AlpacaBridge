### Changed (tooling)
- **The review bot accounts for every decision-record rule in scope** (`.github/workflows/claude-review.yml`, `scripts/check_adr_scope.py`, ci-gates instructions, `/pr-checker`, `/submit-pr`): the review gains a "Decision records" section with one `- NNNN-slug.md rule N: pass|defect|n/a: reason` line per rule the diff falls under, and an `n/a` names the wording or Adoption row that exempts the change. Before posting, the new `check_adr_scope.py --checklist` mode fails the job when a listed rule has no line, a rule gets two verdicts, or a `defect` line sits under the approving sign-off, so an incomplete review never posts as an approval.
- **The review does not run without its rule list**: the scope step now runs the default branch's `check_adr_scope.py` over the base branch's records, so a `stable/*` base without the script still gets a list, and it fails the job when a base with records gives none. It used to fall back to "read docs/decisions/ directly".
