### Changed
- **Bundled libgphoto2 is built without libxml2** (`scripts/build_bundled_gphoto.sh`, `debian/control`): the package no longer depends on `libxml2`, which carried an unfixed Critical advisory in trixie (DEBIAN-CVE-2026-6653, a use-after-free in `xmlParseInternalSubset`). In libgphoto2 2.5.34, libxml2 serves only two experimental entries: the Olympus E-series "XML wrapped" control mode (USB `07b4:0110`) and the `lumix` camlib, which works only over Wi-Fi, which AlpacaBridge's USB autodetect never reaches. Neither is in SUPPORTED-DRIVERS.md. Canon, Nikon, Sony and Olympus OM-D cameras in ordinary PTP mode do not use libxml2. `libxml2-dev` is removed from Build-Depends, the CI build jobs and the development prerequisites, and `scripts/check_bundled_gphoto.sh` now fails if the package Depends names libxml2 or any bundled library or camlib links it.
