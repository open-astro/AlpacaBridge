### Changed (tooling)
- **Beta and nightly `.deb`s carry build provenance and an SBOM** (CI, `.github/workflows/release.yml`, `.github/workflows/nightly-build.yml`, `scripts/dependency_snapshot.py`): each published `.deb` now gets a Sigstore-signed SLSA build provenance attestation and an SPDX SBOM attestation, so `gh attestation verify <file> --repo open-astro/AlpacaBridge` proves which workflow and commit built it. The SBOM comes from the new `dependency_snapshot.py --spdx <file.deb>`: the dependency graph's inventory (vendored SDKs, FetchContent libraries, Build-Depends) rooted at the built package, with runtime dependencies read from the package's own resolved `Depends`. A release dry run builds the SBOM but attests nothing. Stable `.deb`s ship through apt.openastro.net and are not covered.
