### Changed (tooling)

- **The fake ConformU run walks a run list, one record per fake-connectable driver**, CI, issue #2078 (slice 1). `scripts/run_fake_conformu.sh` and the test-only server (renamed `fake_conformu_server`) are no longer written for Sky-Watcher: the script runs ConformU for every `run` row of the new `scripts/conformu_fake_runs.tsv` (vendor, device type, fake, status, slice, report path), and the server builds the row's driver from a small host table. The Sky-Watcher UDP mount is still the only row that runs, with the same report name and `FAKE REPORT:` first line; every other `kFakeConnectableRoster` row is `pending` with the slice that will run it, and each driver with no fake has a `no-fake` record. Docs-drift check 29 fails when the run list and the roster disagree in either direction, so a new fake cannot be left outside the run. The `ConformU fake Sky-Watcher` workflow also runs when the run list or the roster header changes, and the new-vendor checklist names the fake ConformU row.
