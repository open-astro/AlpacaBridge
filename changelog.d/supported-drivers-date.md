### Changed (tooling)
- **Only `/bump-release` moves the `## Updated` date in `SUPPORTED-DRIVERS.md`** (`/commit`, `/conformu`, `/bump-release`): `/commit` and `/conformu` set the line to today's date on every driver or validation change, so open PRs conflicted on that one line (16 edits from 2026-10-16 to 2026-11-01), and with the merge queue on `main` a conflict takes a PR out of the queue. Both skills now leave it alone, and `/bump-release` sets it to the release date as before. Docs-drift check 16 is unchanged: the line still may not be older than the README badge date.
- **`docs/beta-channel.md` describes the `stable/**` protection as it is** (docs): it said the stable ruleset matched `main`'s, which stopped being true when `main` moved to a merge queue with its own required checks. It now lists the stable ruleset's own rules: pull requests only, no deletion or force-push, merge commits only, `Build + test (arm64)` required and the branch required to be up to date.
