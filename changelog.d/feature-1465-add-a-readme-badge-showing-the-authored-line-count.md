### Changed

- **README shows how much code the project authored** (docs, tooling, issues #1465 and #2079): a new "Authored code" badge beside the existing ones shows the non-blank line count of tracked first-party C/C++, Python, shell and web UI files under `AlpacaCore/`, `AlpacaHTTP/` and `scripts/`, rounded to the nearest 1,000. Vendored SDKs and the bundled libgphoto2 (`AlpacaCore/external/`) are not counted. The number is published on every push to `main` and the badge reads it through the shields.io endpoint, so no pull request or release edits it; `python3 scripts/check_docs_drift.py --badge` prints the current count, the endpoint JSON and the README badge line. Docs-drift check 25 fails on a missing badge, a static line-count badge or an endpoint that reads another file, and it keeps a count floor. Self-test fixtures cover each of those cases and the path filter.
