### Changed

- **Celestron async slew, Park and pulse-guide bodies run on the shared operation slot** (AlpacaCore, issue #973): the telescope driver's `slew_task_thread_`, `pulse_task_threads_[2]`, `task_wait_for` and `reap_*` helpers are replaced by `util::AsyncOperation` (one slot for the slew and Park bodies, one per axis for the pulse-guide chunk chain), so no raw `std::thread` member remains; behaviour is unchanged and the existing `test_celestron_async_park.cpp` and `test_celestron_async_slew_failure.cpp` cases still pass. A start the OS refuses after a goto was cancelled now cancels the GOTO and stops both axes before the call fails (`Celestron slot - a refused goto start stops the mount when it replaced a goto`, `Celestron slot - a refused park start stops the mount when it replaced a goto`); a refusal with nothing in flight sends no stop (`Celestron slot - a refused goto start on an idle mount cancels nothing`). Fake mount only, ConformU not re-run.
