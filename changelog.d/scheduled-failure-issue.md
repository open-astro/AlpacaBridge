### Added (CI)
- **A failed scheduled run opens an issue** (`.github/workflows/scheduled-failure.yml`, `scripts/scheduled_run_issue.py`, issue #1352): a red nightly build, CodeQL scan, OSV scan or dependency-update run on main was visible only in the Actions tab. A failed, timed-out or never-started scheduled or dispatched run now opens one issue for its workflow (`bug`, `P3`), or comments on the one already open, and the next successful run closes it, unless one of its jobs was skipped (a nightly that found nothing new to build); a cancelled run changes nothing. The `docs-drift` job runs the script's `--self-test`.
