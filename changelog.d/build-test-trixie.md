### Changed (tooling)
- **The vendor-neutral CI test job runs on Debian 13** (CI, `.github/workflows/ci.yml`): `Build + test (arm64)` now runs in a `debian:trixie` container, the distribution AlpacaBridge ships for, so the core and HTTP suites build with trixie's gcc 14, glibc and Catch2 instead of the Ubuntu 24.04 runner's gcc 13. Before, only `package-deb` built on trixie, and it runs no tests. The suite runs as an unprivileged user inside the container (root ignores file modes, which broke a read-only-directory case), and the job installs `python3` for the beta VERSION check. This is a trial on the cheapest test job; the all-vendors and sanitizer jobs stay on the Ubuntu runner for now. Its compiler cache has a new key prefix, `ccache-build-test-trixie-`, since gcc 13's objects are no use to gcc 14.
