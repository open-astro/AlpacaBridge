### Changed (tooling)
- **Pre-flight runs the quick set by default** (`scripts/ci_preflight.sh`, `/submit-pr`, `/pr-checker`, `/bump-release`, `/driver-build`, `docs/development.md`, ci-gates instructions, issue #1446): the default run now does every gate that needs no build (clang-format, the Python gates, the beta VERSION split, cppcheck, shellcheck, the web UI JavaScript and zizmor) and takes seconds instead of up to an hour. The build and test gates (both `run_all_tests.sh` passes, clang-tidy and the ASan+UBSan pass) run with `PREFLIGHT_FULL=1` and are reported `[SKIP]` otherwise; CI runs them on every PR. The script also runs on macOS's stock bash 3.2 now: `mapfile` is replaced by a portable reader, and an empty changed-file list no longer aborts the change-scoped gates under `set -u`.
- **The review bot waits for CI's build and test jobs** (`.github/workflows/claude-review.yml`): the `review` job first waits up to 45 minutes for `build-test`, `build-vendors`, `sanitizers` and `sanitizers-tsan` on the PR head, and fails before the agent runs when one is red, so a red push no longer pays for a review the next push throws away. Its timeout is 75 minutes, and the `/pr-checker` and `/submit-pr` verdict polls wait 80 minutes and report that failure as exit `4` (CI red: fix and push) or exit `5` (CI did not finish in time: approve or wait, then re-run the review), not as a broken review workflow.

### Fixed (tooling)
- **The instruction-structure self-test passes on macOS** (`scripts/check_instruction_structure.py`): its fixture root is resolved, so `/var` versus `/private/var` in the temporary directory no longer fails the "rename mutation target is not in the fixture" assertion, which made `check_docs_drift.py --self-test` fail on every Mac.
