### Added (tooling)
- **PR template gate** (CI, `scripts/check_pr_template.py`, `.github/workflows/pr-body.yml` job `pr-template`, pre-flight gate 2b3): a PR body must keep every `## ` section of `.github/PULL_REQUEST_TEMPLATE.md`, each with content of its own, and the Checklist's `- [ ]` items. GitHub fills the template in only for a PR opened from the web page with an empty body, so bodies passed through `gh pr create --body`, the API or an agent skipped it (#836, #848 and #857 since the template landed in #797). The rules are read from the template itself; a heading `A or B` also accepts `## A` or `## B`. Bot PRs skip the job, `/bump-release` now fills the template for the release PR, and `/submit-pr` runs the check before submitting. Not a required check.
