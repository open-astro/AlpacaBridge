### Added

- **Devices tab shows a connection status dot in front of each device name** (AlpacaHTTP web UI): `GET /management/v1/configureddevices` now carries a boolean `Connected` per loaded device (omitted if `get_connected()` throws) and, for drivers that latch a link fault (Celestron, SynScan, Sky-Watcher, iOptron, Gemini PDH switch, WandererAstro cover, filter wheel and box), a `LinkFault` string from the new `AlpacaDriver::get_link_fault()` hook. The dot is green (connected and replying; pulsing, off under `prefers-reduced-motion`), yellow (loaded, not connected) or red (`LoadError`, `LastConnectError`, any `LinkFault`, or unknown), with the state in its `title` and `aria-label`, and refreshes every 5 s only while the Devices tab is visible. Drivers without a latch and report no `LinkFault`. Covered by `test_routing` ("configureddevices Connected field") and `deviceStatus` in `AlpacaHTTP/tests/web/format.test.js`.
