### Added (tooling)
- **Beta channel release tooling** (release process, `release.yml`, `scripts/release_tag.py`, `scripts/changelog_fragments.py`, `scripts/check_docs_drift.py`, `docs/beta-channel.md`): a tag `vX.Y.Z-beta.N` now publishes a GitHub pre-release from `docs/releases/X.Y.Z-beta.N.md` with no dated CHANGELOG section, after mapping the tag to the `X.Y.Z~betaN` VERSION spelling (`release_tag.py --self-test` covers the mapping and the Debian order). `changelog_fragments.py` accepts a `~betaN` VERSION for `--bump --version` and `--preview --version`, docs-drift check 4 accepts a beta README badge, `changelog_to_deb.py` matches a beta `VERSION` against the legacy UNRELEASED label of its base version, CI and CodeQL also run on pushes to `stable/**`, and `/bump-release`, `/submit-pr` and `/pr-checker` gain beta, stable-branch and merge-down modes. AlpacaCore and AlpacaHTTP CMake pass `project()` only the numeric part of `VERSION`, so a `~betaN` VERSION configures, and keep the full string in `ALPACACORE_VERSION` and `ALPACAHTTP_VERSION`. The update card writes a beta `X.Y.Z~betaN` in its tag spelling `X.Y.Z-beta.N` when it builds the release-notes and Release page links, so a beta offered by the card shows its notes and links to its pre-release. `release.yml` gains a `workflow_dispatch` dry run that builds the notes for a named tag and publishes nothing; both CMakeLists read `VERSION` through one helper, `AlpacaCore/cmake/AlpacaBridgeVersion.cmake`, which `scripts/check_beta_configure.sh` (run by the `build-test` CI job) tests with `cmake -P` over sample values, with no configure; `scripts/release_tag_cases.txt` pins the tag mapping and the card's inverse to one list; `changelog_fragments.py --bump` warns when a beta `VERSION` is bumped off a `stable/` branch. A merge-down PR is opened from a short-lived head named per receiving branch, `merge-down/X.Y-to-main` or `merge-down/X.Y-to-X.Z` for a hotfix into a newer stable branch (never `stable/X.Y` itself, which `delete_branch_on_merge` would delete and update-branch would pollute with `main`), after a ruleset protecting `stable/**` is confirmed (each ruleset read by id, since the list endpoint carries no conditions). A merge down keeps the receiving branch's `VERSION` and README badge, so `main` never carries a beta `VERSION`; only a stable release newer than `main`'s comes across. `--release` takes a bare `X.Y.Z` only, so a beta cannot consume the fragments. A beta `.deb` gets a `beta` stanza dated noon UTC on the README badge date (`changelog_to_deb.py --date`, passed by `build_deb.sh`) instead of `UNRELEASED` with the build time, so builds are reproducible. `release.yml` refuses a beta tag whose commit is not on the `stable/X.Y` of its own X.Y, fetching that one branch's history from a depth-1 checkout; a stable tag is gated as before by its bare `VERSION` and dated CHANGELOG section. `--bump` and `--preview` read the `VERSION` file beside the changelog as their floor, so both name the same version; an impossible `--date` is refused by both changelog scripts; `changelog_fragments.py` owns the `X.Y.Z~betaN` spelling (`is_beta()`, `--is-beta` for shell scripts, embeddable patterns with no capturing group), which `changelog_to_deb.py`, `build_deb.sh`, `check_beta_configure.sh`, `check_docs_drift.py` and the `release_tag.py` self-test use; a `VERSION` that does not parse is reported instead of silently dropping the floor; only a beta matches its base UNRELEASED label; `build_deb.sh` reads the badge date through `check_docs_drift.py --badge-date`; `release_tag_cases.txt` allows trailing comments and is read by one rule in Python and C++; `/deploy-remote-test` reads the asset URL back from GitHub instead of building it from a `VERSION` that may contain `~`; `scripts/merge_down.py` decides the `falsified-by` exemption in CI and in the pre-flight alike: the head name, the base it names, a same-repository head, no commit that is not already on `stable/X.Y`, and no merge commit that edits a test file beyond git's own re-merge of its parents. No user-visible change until a beta is cut.
