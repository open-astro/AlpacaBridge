### Fixed

- **A Sky-Watcher goto, Park or FindHome that the slew slot refuses to start now stops the axes** (SkyWatcher, issue #968): the refused start had already marked the running slew Superseded, so nothing stopped the axes it was driving and they kept moving while the call failed; when the refused start had replaced a running slew, the rollback now stops both axes and clears `Tracking` like AbortSlew (`start_slew_body()`); a refusal that replaced nothing leaves a tracking mount tracking. Covered by the `refused ... start leaves the axes stopped` cases and the idle-tracking case in `test_skywatcher_async.cpp`.
