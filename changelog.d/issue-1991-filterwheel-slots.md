### Changed

- **One home for filter wheel slot data**, all seven filter wheel drivers (ZWO EFW, QHY integrated CFW, QHY CFW3, Player One, ToupTek AFW, iOptron iEFW, WandererAstro SFW), issue #1991. Names, focus offsets, the `LRGB` shorthand, the `Filter N` defaults, the length check and the resize at connect now live in one `util::FilterWheelSlots` value instead of seven copies. Player One now expands a lone uppercase shorthand token such as `LRGBH` on a connected wheel and when a configured `filterNames` token is applied at Connect, as the other drivers do (before, a configured `LRGBH` became one name followed by `Filter 2` to `Filter 5`). A ZWO wheel opened by SDK id now accepts a names or offsets list of any length after a Disconnect (the count is known again at the next Connect). An iOptron wheel no longer expands a lone shorthand token while disconnected. WandererAstro still checks the length while disconnected. Fake-only tests; ConformU not re-run.
