### Fixed

- **Pointing helpers and motion guards fail closed on a non-finite position**, shared mount utilities, issue #2464. `shortest_ra_delta_hours` wraps with `std::fmod` instead of `while` loops, so an infinite RA no longer hangs the calling thread (an HTTP request or a slot body) and a NaN or infinite input returns NaN; finite results are unchanged. `axis_miss_arcsec` reports a non-finite position as an infinite miss, so the stillness check and `LandingGate` never read a NaN position as still or landed, and `angular_separation_arcsec` returns 180 degrees for a non-finite input by an explicit check rather than by accident of `std::min`. The `enforce_motion_deadline` and `run_verified_stop` docs now state that the deadline must be armed and that `clock` must be the one `ctx` waits on, and the ASCOM contract instructions name the `motion_policy.h` constants instead of repeating their values.
