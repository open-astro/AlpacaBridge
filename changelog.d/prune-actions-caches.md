### Added (CI)
- **Superseded Actions caches are deleted after each run on main** (`.github/workflows/cache-prune.yml`, `scripts/prune_actions_caches.py`, issue #1350): the ccache and CodeQL caches are saved under a key ending in the commit SHA and restored by prefix, so every push to main added about 2 GB that could never be restored again, the repository passed GitHub's 10 GB cache limit, and GitHub evicted caches still in use (the nightly's optimized ccache did not survive to the next night). After each CI, Nightly Build and CodeQL run on main the workflow keeps the newest cache per ref and key prefix and deletes the rest; keys without a commit SHA (the cppcheck build) are left alone. The `docs-drift` job runs the rule's `--self-test`.
