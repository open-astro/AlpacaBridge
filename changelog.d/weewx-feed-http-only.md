### Fixed
- **WeeWX feed URL accepts only http and https** (`AlpacaCore/src/vendors/weewx/weewx_observingconditions_driver.cpp`): the feed fetch passed the configured URL to libcurl with every protocol it was built with enabled, so a `file://`, `ldap://` or other non-HTTP URL was fetched and a `file://` path holding valid JSON connected the driver. The fetch is now limited to http and https, also after a redirect, as the software update check already was; any other URL fails to connect with DriverException. With this, no libcurl call in AlpacaBridge can reach LDAP (curl advisory CVE-2026-13608). Covered by the `connect refuses a non-HTTP feed URL` case in `test_weewx_observingconditions.cpp`.
