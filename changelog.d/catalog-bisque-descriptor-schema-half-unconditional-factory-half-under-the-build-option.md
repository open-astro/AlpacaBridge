### Changed
- **Bisque / Paramount (TheSkyX) telescope moved into the device catalog** (AlpacaCore, AlpacaHTTP): the schema (`bisque_schema.cpp`, every build) and factory (`bisque_catalog.cpp`, only under `ALPACACORE_ENABLE_BISQUE`) replace the router's register arm, its sanitize branch and its driver include. The vendors-OFF text stays "Bisque support not enabled. Rebuild with -DALPACACORE_ENABLE_BISQUE=ON", and an empty host is still refused from the API with "Host is required for Bisque/TheSkyX connection" and warned about for a saved config. `GET /management/v1/devicecatalog` now lists the `bisque` telescope descriptor. The registration log line now reads "Registered Bisque telescope", and a wrong-type value is refused with the catalog's "Device config field '<key>' has the wrong type" message. `scripts/check_layering.py`'s AlpacaHTTP vendor-include baseline drops from 33 to 32.
