### Changed

- **Web UI vendor list and index fields come from the device catalog**, AlpacaHTTP web UI, issue #1624. The Add and Edit Device form reads `GET /management/v1/devicecatalog` once per page load (`web/catalog_schema.js`) and offers a vendor for a device type only when the catalog has an available descriptor for the pair; the hand-kept vendor availability blocks and the `INDEX_FIELDS` table in `app.js` are gone, and the auto-numbered index fields are derived from the catalog's `EnumerationIndex` fields. A failed catalog load is shown as text, the vendor select stays disabled, and opening the form again retries. Editing a Gemini Power & Data Hub (a Switch) now keeps its vendor instead of opening with none selected. Covered by `AlpacaHTTP/tests/web/catalog_schema.test.js`.
