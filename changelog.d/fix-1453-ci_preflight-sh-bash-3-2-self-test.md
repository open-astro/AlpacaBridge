### Added

- **`ci_preflight.sh --self-test`**, CI tooling, issue #1453. The script now tests itself under `/bin/bash -u`: `read_lines` keeps spaces, `$(...)` text and quotes literal and gives 0 elements on empty input; no bash 4 construct (`mapfile`, `readarray`, `declare -A`, `${x,,}`, `|&`) appears and `CHANGED` is only expanded with the empty-array guard; an empty diff (`PREFLIGHT_BASE=HEAD`) records SKIP for clang-format, clang-tidy, cppcheck, shellcheck, javascript and zizmor with no unbound-variable abort and every gate in the summary; a quick run records the quick-run SKIP for both build+test gates and sanitizers, and checks that clang-tidy and those gates are only run through `full_only`. Each failed check is named and the exit status is non-zero. The ShellCheck CI job runs it on every PR. Covered by `scripts/ci_preflight.sh` (`self_test`).
