### Changed
- **QHY CCD SDK updated from 26.06.04 to 26.07.28** (AlpacaCore, issue #1130): the vendored `libqhyccd` under `AlpacaCore/external/QHY/sdk_linux_arm64_26.07.28/` reports build 26.07.28.10. The public headers only add declarations (`ParseGPSFromFrame`, `GetQHYCCDDDRBufferValue`, `RegisterPnpEventUVLO`, QHY676 and QHY5III662 device types), so the wrapper needed no change; the udev rules add four fxload entries (QHY6060PRO, QHY676, QHY5III662, QHY992 deep cooling) and the firmware set adds QHY676, QHY5III662 and QHY992 deep cooling images. The vendor changelog (`https://www.qhyccd.com/html/prepub/log_en.md`) lists the release without notes. ConformU was not re-run.
