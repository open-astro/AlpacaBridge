### Fixed
- **WeeWX ObservingConditions: AveragePeriod, TimeSinceLastUpdate("") and unknown sensor names follow IObservingConditionsV2** (AlpacaCore, issue #778): the readings are instantaneous, so `AveragePeriod` now always reads 0.0 and writing any other value raises `InvalidValue` (it used to accept and return any non-negative value); `TimeSinceLastUpdate("")` returns the time since the most recent update of any sensor (it returned -1 while data was fresh), and still -1 before any sensor has reported, as a named sensor does; a sensor name IObservingConditions does not define raises `InvalidValue` from `TimeSinceLastUpdate` and `SensorDescription`, connected or not (it was `PropertyNotImplemented`), while a defined sensor the station does not serve keeps `PropertyNotImplemented`. The tier-1 contract sweep now probes both members with an unknown name on ObservingConditions drivers.
