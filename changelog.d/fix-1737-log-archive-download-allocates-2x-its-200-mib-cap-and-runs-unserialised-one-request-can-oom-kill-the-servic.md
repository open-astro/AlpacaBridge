### Changed
- **Log archive download is capped and serialised** (AlpacaHTTP, issue #1737): the log archive download (`GET /management/v1/logfiles?download`) is now capped at 32 MiB (was 200 MiB) and builds one archive at a time; a second request gets an Alpaca error 0x40B "Log archive build already in progress; retry shortly" instead of using more memory (issue #1737). The web UI shows that message instead of saving it as a log file.
