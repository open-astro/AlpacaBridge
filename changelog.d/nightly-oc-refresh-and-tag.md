### Fixed (tooling)

- **Nightly build no longer fails when main changes a workflow mid-run** (CI, issue #2783): GitHub refuses a `GITHUB_TOKEN` tag write whose commit has other `.github/workflows` files than the default branch's tip, so the 2026-11-27 nightlies built a good `.deb` and then failed to move the `nightly-build` tag. The tag step now compares the two workflow trees first and, when they differ, skips publishing with a warning; the next run builds the new tip.
- **remotealpaca stress cases storm again until what they check has happened** (AlpacaCore tests, issue #2783): the nine cases that check a command reached a connected upstream (Refresh, MoveAbsolute, Halt, SetSwitch, SetSwitchValue, AbortSlew, Move), and the SafetyMonitor case that requires a lost link's false IsSafe read, could spend a whole 750 ms storm under ASan + UBSan without one, and failed the nightly sanitizer job on 2026-11-24 and 2026-11-27. They now run up to eight storms until what they check has happened.
