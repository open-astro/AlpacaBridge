### Security

- **Packaging: the installed udev rules no longer let every local user open a camera, wheel or focuser**, issue #2290. The vendor rules shipped `MODE="0666"` on whole USB vendor IDs. The `.deb` and the source installers (`build_and_run.sh`, `install_alpaca_service.sh`) now install each rule through `scripts/tighten_udev_rules.sh`, which rewrites a world-accessible mode to `GROUP="plugdev", MODE="0660"`; the vendor files under `AlpacaCore/external` are not edited. The package creates `plugdev` if a host lacks it and keeps the service user in it, and the source installers add the installing user (`ALPACA_ADD_PLUGDEV=OFF` skips it). Other software on the same board that opens these cameras (for example KStars/INDI or PHD2 under a desktop account) must run as a `plugdev` member. Docs-drift check 29 fails on an installed rule that lets every user open a device. The NetworkManager polkit grant stays as it was: NetworkManager offers no Wi-Fi-only form of `network-control` or `settings.modify.system`, and decision 0007 now says so.
