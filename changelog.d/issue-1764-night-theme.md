### Added
- **Web UI: a red night theme** (AlpacaHTTP web UI, issue #1764): a **Night** button in the header switches the page to red on black (palette D of the issue: text `#f3170b` on `#000000`, 4.94:1), to keep the operator's eyes dark-adapted. It has one text colour and no green, blue or amber. Buttons, inputs and switches are outlined, the active tab is underlined and bold, and the logo becomes a red silhouette; the favicon is unchanged. Status is shown by shape as well as colour: a solid dot when a client is connected, a hollow ring when idle or quiet, a square on an error, with the label and tooltip kept. The choice is kept in this browser's local storage and applied before the page first draws; when storage is blocked, the button still works until the page reloads. The default theme looks the same as before.

### Added (tests)
- **Night theme** (issue #1764): nine `night_theme.test.js` cases compute the WCAG contrast (4.5:1 for text, 3:1 for control edges) and the red-only hue from the night token block, and check the status shapes, the logo silhouette, the toggle with a throwing or missing local storage, the first-paint script in `<head>` and the header button.
