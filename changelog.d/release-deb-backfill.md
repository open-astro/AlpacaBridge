### Added (tooling)
- **Release backfill workflow attaches the .deb to older Releases** (CI): Releases v3.0.0 through v4.1.0 had no `.deb` and the apt repository keeps only the newest version, so those versions could not be installed. `.github/workflows/release-backfill.yml` (manual dispatch with a tag) rebuilds that tag's `.deb` and `alpacabridge-dbgsym` package from the tag's own source in the `debian:trixie` container `release.yml` uses, attaches them with their `.sha256` files under the same asset names, and adds a build provenance attestation. It refuses a tag with no Release and never replaces a `.deb` a Release already has.
