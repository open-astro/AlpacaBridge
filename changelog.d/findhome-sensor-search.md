### Added
- **Telescope drivers** (AlpacaCore): a read-only `findhomeissensorsearch` Action on every telescope driver says whether FindHome is a real sensor search, so a client can trust AtHome after a FindHome it sent. It returns `{"sensor_search":<bool>,"method":"<word>","model":"<model>"}` and is listed in SupportedActions while connected. It is true for the iOptron HAE29C EQ (the zero sensor search), a Celestron NexStar home-switch model (CGE Pro, CGX, CGX-L) whose home switches also answer on the AUX bus (the model is required because a hand controller may answer for an absent switch, for example on an AVX), the Celestron CGX USB driver, and a Sky-Watcher board with home index sensors on both axes (the Wave). It is false for every other model and for Bisque, OnStep, ZWO AM and SynScan. Tested on the fake mounts only.
