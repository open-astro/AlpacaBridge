### Fixed (CI)
- **Nightly `.deb` no longer named after the stable release it is not part of** (CI): with `stable/5.0` cut, a nightly from `main` was stamped `5.0.0~nightly…` because a merge-down keeps `main`'s `VERSION` at 4.2.0 and `changelog_fragments.py --bump` then prints 5.0.0, so its asset read as a 5.0.0 build and dpkg sorted it below 5.0.0, which would have "upgraded" a tester back to the stable line without `main`'s fixes. The new `scripts/nightly_version.py` raises `<next>` to at least `X.(Y+1).0` past the newest `stable/X.Y` branch or `vX.Y.Z[-beta.N]` tag, so tonight's build is `5.1.0~nightly…`; the `dependency-submission.yml` and `osv-scan.yml` consumers match the asset by glob and the `nightlyYYYYMMDDHHMM` stamp, not the version, and need no change; see docs/beta-channel.md.
