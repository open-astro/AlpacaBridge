### Changed

- **SynScan async slew, Park and pulse-guide bodies run on the shared operation slot** (AlpacaCore, issue #984): the telescope driver's `slew_task_thread_`, `pulse_task_threads_[2]`, `task_wait_for` and `reap_*` helpers are replaced by `util::AsyncOperation` (one slot for the slew and Park bodies, one per axis for the pulse-guide stop timer), so no raw `std::thread` member remains. The Celestron and SynScan Park flows now share one `util::run_park_slew()` (`AlpacaCore/include/alpacacore/util/park_slew.h`). A start the OS refuses after a goto was cancelled now cancels the GOTO and stops both axes before the call fails (`SynScan slot - a refused goto start stops the mount when it replaced a goto`, `SynScan slot - a refused park start stops the mount when it replaced a goto`); a refusal with nothing in flight restores the flags and sends no stop (`SynScan slot - a refused goto start on an idle mount cancels nothing`). Fake mount only, ConformU not re-run.
