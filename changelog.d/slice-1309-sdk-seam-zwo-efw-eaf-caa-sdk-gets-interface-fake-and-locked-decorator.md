### Changed
- **ZWO filter wheel driver reaches the EFW SDK through an injectable interface** (AlpacaCore, issue #1309; remaining: EAF/CAA shared fakes and Locked decorators in a follow-up PR): `ZWOEFWSDK` (`zwo_efw_sdk.h`) is implemented by the existing `ZWOEFWSDKWrapper` singleton, and `create_zwo_efw_filterwheel` and `create_zwo_efw_filterwheel_by_index` gain overloads taking it. The two-argument factories still pass the real wrapper, so runtime behaviour is unchanged. The new `FakeZWOEFWSDK` can script the wheel's moving window (Position reads -1 after a move, and a move during it is refused with `InvalidOperation`, as `EFW_ERROR_MOVING` is). It and its `Locked` decorator are covered by fake-SDK cases in `test_zwo_seam_fakes.cpp`, a connected `[stress]` registration in `test_zwo_concurrency_stress.cpp` and a tier-2 row in the contract sweep. ConformU was not re-run.
