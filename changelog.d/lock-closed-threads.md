### Added (CI)
- **Closed issues and pull requests are locked after 14 days without activity** (`.github/workflows/lock-threads.yml`): a scheduled `dessant/lock-threads` run every six hours locks them with the reason `resolved`, so a new report goes into a new issue rather than a comment on an old merged PR (a 5.0.2 regression was reported on merged PR #1100). Threads closed from 2026-11-10 on get a comment linking to a new issue; the roughly 1,600 older closed threads are locked without a comment, so their subscribers get no notification. Collaborators can still comment on a locked thread. `scheduled-failure.yml` watches the workflow.
