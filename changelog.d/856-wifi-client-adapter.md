### Added
- **Wi-Fi: choose the client adapter** (AlpacaHTTP, web UI, issue #856): the Wi-Fi panel gets a Client adapter list, so a board can keep its hotspot on the built-in radio and join networks with a USB adapter. The choice is stored as the adapter's permanent MAC (`config/wifi_client_adapter`), never an interface name, so it survives a reboot or a different USB port. `GET /management/v1/wifi/status` adds `Adapters` (`Interface`, `Mac`, `IsAp`) and `PreferredMac`; `PUT /management/v1/wifi/adapter` with `{"Mac": "..."}` sets it and `{"Mac": ""}` clears it. A malformed MAC, an unlisted MAC and the hotspot's own interface are refused. On a board with more than one Wi-Fi device a change re-pins every saved client profile (only its `interface-name`), never the hotspot profile, and a connect re-pins a profile whose pin went stale. An unplugged preferred adapter is logged at INFO and the automatic pick is used. Single-radio boards behave as before.

### Added (tests)
