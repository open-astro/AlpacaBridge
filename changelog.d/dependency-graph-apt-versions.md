### Fixed
- **The dependency graph shows Debian and Ubuntu package versions** (`scripts/dependency_snapshot.py`, `.github/workflows/dependency-submission.yml`): the `debian/control` packages and the CI apt tools were listed with no version, because `debian/control` uses `>=` constraints rather than exact pins. The submission job now asks `apt-cache policy` in the `debian:trixie` image (and on the Ubuntu 24.04 runner for the CI tools) and records the version apt would install, for example `cmake 3.31.6-2`. An exact `(= X)` pin still wins; a package with no candidate stays unversioned and is named in a warning. Pinned by the new apt-candidate case in `dependency_snapshot.py --self-test`.
