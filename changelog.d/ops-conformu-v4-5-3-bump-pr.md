- **ConformU standard is the 4.5.3 release (build 56334)** (`/conformu`, `/driver-build`, `SUPPORTED-DRIVERS.md`, issue #1576): `/conformu` installs `conformu.4.5.3.linux-arm64.tar.gz` from the ConformU v4.5.3 GitHub release with a sha256 check and unpacks it with `tar xzf` (the arm64 asset is now a gzip archive, not `.tar.xz`).
