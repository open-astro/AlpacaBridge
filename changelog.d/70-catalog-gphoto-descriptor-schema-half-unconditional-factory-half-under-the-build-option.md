### Changed
- **gphoto camera moved into the device catalog** (AlpacaCore, AlpacaHTTP): the schema (`gphoto_schema.cpp`, every build) and factory (`gphoto_catalog.cpp`, only under `ALPACACORE_ENABLE_GPHOTO`) replace the router's register arm, its sanitize branch and its driver include. The vendor-off refusal text and the registration path are unchanged, and `GET /management/v1/devicecatalog` now lists the `gphoto` camera. One edge differs: `cameraIndex` is now an integer field, so `configuredevice` refuses a JSON float with a fractional part (such as `1.5`) or a boolean as the wrong type, and a persisted entry holding such a value now fails to load where the deleted arm loaded it as index 1; re-save it with a whole number.
