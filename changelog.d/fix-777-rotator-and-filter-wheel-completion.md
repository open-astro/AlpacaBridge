### Fixed
- **WandererAstro rotator: a move with no completion report no longer claims arrival** (AlpacaCore, issue #777): when the controller never reports the end of a move (typically no DC power), `Position` keeps the last confirmed angle instead of the target, and `IsMoving` throws a driver error naming the missing report and the power supply until the next move, `Halt`, `Sync` or reconnect (`test_wandererastro_rotator.cpp`, "No completion report keeps Position and faults IsMoving").
- **ZWO CAA rotator: `StepSize` throws `PropertyNotImplemented`** (AlpacaCore, issue #777): the SDK reports no step size, so the hard-coded `0.0` is gone.
- **QHY CFW: a failed move or a wheel at rest off-target no longer reads -1 forever** (AlpacaCore, issue #777): a throwing `move_cfw` clears the pending target so `Position` returns live reads, and a wheel that keeps reporting the same non-target slot for 2 s (at least 3 reads) ends the move and reports that slot; transit readings still read -1.
