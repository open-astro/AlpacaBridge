### Added (tooling)
- **Decision-record gate** (CI, issue-free; `docs/decisions/README.md` "Changing a record"): a PR that changes `docs/decisions/` needs a collaborator (write, maintain or admin) to comment `ADR authorized <head sha>`. `scripts/check_adr_authorization.py`, run from the default branch by the new `.github/workflows/decision-records.yml` on every push and comment, posts the `adr-authorization` commit status. `.github/CODEOWNERS` names the code owners of the records and of the gate. The PR template gains a required `## Decision records` section, which the new `decision-records` PR-body job (`scripts/check_adr_scope.py`) checks names every record the PR changes. The review bot now gets the decision-record rules the diff falls under, computed from the base branch, and reports a broken rule as a defect.
