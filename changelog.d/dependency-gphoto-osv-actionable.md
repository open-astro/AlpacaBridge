### Changed (tooling)
- **OSV summary issues list only actionable findings** (`scripts/dependency_updates.py --osv-summary`, `.github/workflows/osv-scan.yml`): the first scan's issue (#1135) listed 100 High/Critical findings, nearly all unfixed or disputed advisories in Debian base-system packages, several repeated once per binary package. A finding now opens an issue only when it is CVSS 7.0 or more, has a `fixed` version in its Debian trixie entry and is not rated `unimportant`; the row names the fixed version, one advisory reported through several binary packages is one finding, and the `.deb`'s other findings (scope below) stay in code scanning only. The summary marker becomes `osv2`, so #1135 suppresses nothing. Both the summary issue and the code-scanning upload are now scoped to the `.deb`'s own runtime dependencies (its `Depends`, mapped to Debian source packages), without the C/C++ runtime (glibc, gcc) and without findings Debian rates `unimportant`: on the first scan that is 43 of 298 alerts (curl, libgphoto2, systemd, libusb); the base system's findings no longer reach code scanning.

### Added (tooling)
- **Update checks for the gphoto libraries** (`scripts/dependency_sdk_versions.json`, `scripts/dependency_updates.py`): a new `system_libraries` list tracks libraries the build takes from Debian against their upstream releases, starting with libgphoto2 and LibRaw (baseline: the version Debian trixie ships), and the gphoto2 command-line tool is a `documents` entry (new `github-release` provider). `vendors.gphoto` now maps to them instead of a `no_upstream` reason, and `--check` fails on a `system_libraries` entry without its repository or baseline.
- **Changelogs in dependency issues** (`scripts/dependency_updates.py`): update and document issues end with a `## Changelog` section when the source has one: GitHub release notes (in a code block, so mentions and issue numbers in them do not ping or link), a compare link for tag-only releases and changed INDI files, ZWO's per-SDK update log, and the QHY and libgpiod changelog pages.
