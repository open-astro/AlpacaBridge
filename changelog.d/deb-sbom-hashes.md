### Changed (packaging)
- **Vendor SDK libraries ship unstripped** (`debian/rules`): `dh_strip` and `dh_dwz` now skip `/usr/lib/alpacabridge/`, so each vendor `.so` in the `.deb` is byte-identical to the copy in `AlpacaCore/external/`. The installed size grows by about 2.3 MB: 1.3 MB for the two ZWO ASI camera library files, 0.9 MB for the QHY library, and under 0.1 MB for the rest. Stripping only removed symbol tables, so loading and behavior do not change.

### Changed (tooling)
- **The .deb SBOM pins and checks every shipped vendor file** (`scripts/dependency_snapshot.py`, `scripts/dependency_sdk_versions.json`): each SDK entry now carries a `sha256` of its git-tracked files, written by `dependency_snapshot.py --pin`; `--check` (the `docs-drift` CI job) fails when the vendored files change without a new pin, so an SDK bump must touch its entry. `--spdx` fails unless every file under `/usr/lib/alpacabridge/` and `/usr/lib/firmware/` in the built `.deb` is byte-identical to a vendored file of a listed SDK, lists each such file with its SHA-1 and SHA-256 under that SDK, and records the exact version of each Build-Depends package installed in the build environment.
