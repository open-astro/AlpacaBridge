### Fixed

- **QHY camera: a `BinX`/`BinY` write during an exposure fails at once, and ToupTek `AbortExposure` during a stream restart is no longer undone** (issue #771). The QHY bin setter now checks for a live exposure before asking the SDK whether the bin is supported, so it throws `InvalidOperation` instead of blocking `CameraState`, `AbortExposure` and `Disconnect` behind the frame (test `BinX write during an exposure fails at once`). The ToupTek exposure worker re-checks an abort generation under the driver mutex before restarting the stream and before the trigger, so an abort that lands mid-restart returns promptly and is not undone (test `AbortExposure during the stream restart is not undone`).
