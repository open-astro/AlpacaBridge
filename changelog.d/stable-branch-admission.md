### Changed
- **Stable branch admission rule** (docs): `docs/beta-channel.md`, `AGENTS.md` and `/submit-pr` now state when a fix PR may target `stable/X.Y` (a regression from the previous stable, a promotion-milestone issue, or a change that leaves the driver's recorded ConformU result standing), which driver changes target `main` regardless (a new SDK seam or fake, a client-visible capability-flag change, a state-machine rewrite, a driver change that needs a fresh ConformU run and lands without one), and the two overrides (a maintainer admitting a change by name on the promotion milestone, and a multi-driver series already partly on the branch finishing there).
