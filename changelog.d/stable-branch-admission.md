### Changed
- **Stable branch admission rule** (docs): `docs/beta-channel.md`, `AGENTS.md` and `/submit-pr` now state that a fix PR targets `stable/X.Y` only when it fixes a defect or regression introduced after the previous stable release (the last stable tag before `X.Y.0`); a defect that release also had, and every feature, refactor, new driver, test, tooling or docs change, targets `main`. A qualifying fix still targets `main` when it adds a new SDK seam or fake, a client-visible capability-flag change, a state-machine rewrite or a driver change that needs a fresh ConformU run, unless a maintainer admits it by name on the `X.Y.0 promotion` milestone.
