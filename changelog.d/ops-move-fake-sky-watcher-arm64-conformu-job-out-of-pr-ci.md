### Changed (CI)
- **The fake Sky-Watcher ConformU run no longer runs on every PR**, issue #1637. The `conformu-fake` job moved from `ci.yml` to `.github/workflows/conformu-fake.yml` with the same steps (ConformU 4.5.3 pin, `scripts/run_fake_conformu.sh`, artifact `conformu-fake-skywatcher`). It runs on a PR only when the PR touches the Sky-Watcher driver, the fake mount and server, the telescope interface, the shared helpers, the HTTP layer, the run script or its report checker `scripts/check_conformu_reports.py` (the workflow's `paths:` list), nightly on `main` at 04:47 UTC, and on dispatch. `scheduled-failure.yml` watches it, so a red nightly run opens an issue.
