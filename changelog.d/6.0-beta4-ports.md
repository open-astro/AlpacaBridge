### Fixed
- **ZWO and QHY cameras: StartExposure(0) and a duration below ExposureMin run at the minimum** (AlpacaCore, issue #2259): ZWO answered `InvalidValue` for a 0 s bias frame and for any duration below the SDK's shortest exposure, and QHY wrote 0 microseconds to the SDK; both now expose for ExposureMin, as the other cameras do. Ported to 6.0 from main's PRs #2325 (ZWO) and #2343 (QHY), StartExposure only; main's argument-order changes stay in 6.1.
- **QHY camera: a frame read that throws fails the exposure instead of ending the server** (AlpacaCore, issue #2292): the frame read was the one SDK call in the exposure worker outside a `try`, so a throw from it (the SDK wrapper's "camera not open") ended the process; the exposure now fails with that text, raised by `ImageReady`. Ported to 6.0 from main's PR #2372, the QHY frame read only; main's PulseGuide duration bound stays in 6.1.

### Fixed (tests)
- **Gemini flat panel lost-link checks wait for the port release, and the AsyncConnectable race cases hold the task with `ConnectHoldGate`** (AlpacaCore tests, issue #2402): ported to 6.0 from main's PR #2404 with the test-only `connect_hold_gate.h` it needs. The flat panel's `require_lost` checked the port registry as soon as `Connected` read false, before the thread that met the hangup had closed the port; seven AsyncConnectable cases slept 10-20 ms and assumed the task had reached its connect or disconnect work by then, which an ASan+UBSan runner missed. main's PDH staleness case does not exist on 6.0.
- **Gemini focuser, iOptron iEAF and iEFW lost-link checks wait for the port release; the CGX AbortSlew re-home case waits for the AbortSlew, not a 2 s grace** (AlpacaCore tests, issue #2466): each `require_lost` helper checked the port registry as soon as `Connected` read false, the race #2402 fixed for the flat panel, and now waits up to 1 s for the release. "AbortSlew during a re-home sends no further home" gave the AbortSlew 2 s of real time before stepping the clock; it now requires the AbortSlew to have returned, which is when it has cancelled the home body.
