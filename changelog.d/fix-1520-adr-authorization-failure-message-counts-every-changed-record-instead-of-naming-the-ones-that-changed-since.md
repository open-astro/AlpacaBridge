### Fixed

- **`adr-authorization` failure text names the changed records**, CI script `scripts/check_adr_authorization.py`, issue #1520. When an earlier `ADR authorized <sha>` no longer covers the head, the status reads `Authorized at <sha>; <record>.md changed since: comment 'ADR authorized <head12>'`, listing the records whose content differs between that commit and the head (a record added or deleted since counts), or `<n> records changed since` when the names do not fit in 140 characters; the instruction always ends the text. With no valid earlier authorization the text is unchanged. Covered by the `--self-test` cases after "A failure after an aged authorization names the records". A record name with a control or bidi character gives the count form, so PR-controlled text never reaches the job log (self-test cases `a newline in a record name` and `a bidi in a record name`). With several earlier authorizations the last one in statement order is named.
