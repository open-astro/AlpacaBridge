### Changed (docs)

- **Decision records for the ASCOM conformance decisions of 2026-10-21** (docs, issue #1470): decision 0001 now has one time source for `UTCDate`, `SiderealTime` and Sky-Watcher pointing, refusing `UTCDate` writes with `PropertyNotImplemented` while the host clock is NTP-synced (issue #1472); decision 0008 makes `Sync` throw `DriverException` when the rotator offset cannot be saved and deletes a removed rotator's offset (issue #1473); new proposed decision 0018 gives every configured device a persisted GUID `UniqueID` (issue #1471); new proposed decision 0019 lets a Sky-Watcher mount connect without a site and refuses the members that need one until it is set (issue #1474). The driver code still follows the earlier rules until those issues land. Docs only, no behaviour change.
