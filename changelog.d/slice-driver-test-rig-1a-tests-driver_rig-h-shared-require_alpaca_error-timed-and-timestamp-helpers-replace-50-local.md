### Changed

- **Shared driver test helpers**, tests and docs, issue #1782. `AlpacaCore/tests/driver_rig.h` now holds `require_alpaca_error`, `timed`, `parse_timestamp` and `time_stamp_of`, and the 51 local copies of `require_alpaca_error`, 15 more local helpers that only checked one error code (other names or a lambda, for example `require_not_connected`, `require_code`, `check_driver_exception`; callers that used `CHECK` now `REQUIRE`) and the copied `timed` and timestamp helpers (three snapshot files, the ZWO async slew and telemetry stress files, the Celestron telescope and QHY camera files and `getter_stall_probe.h`) are gone; timestamp parses written inline in a test body stay, and the two ToupTek files keep `elapsed_of` and `time_of`, each a `timed` that swallows the error. Covered by `AlpacaCore/tests/test_driver_rig.cpp`: the helper fails on no throw, on a wrong code and on a non-Alpaca exception, `timed` returns the elapsed time and `parse_timestamp` reads the `TimeStamp` format. `testing.instructions.md` now says a driver's `contract_sweep.h` entry covers 8+1 cases 3 and 4 and part of case 6 (case 8 stays in the vendor file), that no test file keeps its own copy of a shared helper under any name, and that a test of a clock-adopted driver waits through the fake clock, not `sleep_for` (decision 0005 rule 2; older tests that still sleep move their driver-timer waits when those waits change).
