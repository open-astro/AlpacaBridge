### Fixed

- **Bounded TCP connect: a lookup with no address and no error is "host not found"**, shared mount network connect (ZWO, OnStep), issue #2711 follow-up. `util::lookup_tcp_host()` turns a resolver result with neither into "host not found (no address)", so ZWO's endpoint lookup, which reads the first address when there is no error, cannot read past the end with an injected resolver; the system resolver already reported an error in that case. The header comment of `AlpacaCore/include/alpacacore/util/tcp_connect.h` now names the wrappers that use it (ZWO and OnStep; the others in #2712). Covered by `AlpacaCore/tests/test_tcp_connect.cpp`.
