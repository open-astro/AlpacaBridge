### Changed (tooling)
- **Dependency snapshot picks the newest nightly `.deb` by its timestamp and no longer skips udev rules paths it cannot expand** (CI tooling, issue #1239): `scripts/dependency_snapshot.py --newest-deb` orders by the `nightlyYYYYMMDDHHMM` stamp (so `5.0.10` beats `5.0.9`) and ignores a file with no stamp (exit 1 when `.deb` files exist and none has a stamp, which fails the fetch step); `dependency-submission.yml` calls it once. `--check` now fails when a `.rules` path in `debian/rules` uses a `?=`, `+=` or `$(shell ...)` variable or holds an unresolved `$(VAR)` in a path whose text before the variable is the vendored tree or one of its ancestor directories. Covered by new `--self-test` cases.
