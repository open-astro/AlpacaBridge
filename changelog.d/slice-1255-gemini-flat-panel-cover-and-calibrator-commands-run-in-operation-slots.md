### Changed

- **Gemini Rev2 and Pro flat panel: cover and calibrator commands run in operation slots** (Gemini, issue #1255): `OpenCover`/`CloseCover` and `CalibratorOn`/`CalibratorOff` bodies run in two `util::AsyncOperation` slots instead of hand-rolled threads, disconnect and the destructor cancel and join them (queued light commands that never reached the wire are dropped), and the idle `CoverState` cache reads an injected `util::TaskClock`. Calibrator commands still reach the wire in submission order and none is skipped (`Gemini Flat Panel Slots - calibrator commands queued behind a cover move return at once and run in order`); a body that fails on the wire now makes `CoverState` or `CalibratorState` report `Error` until the next command of that family (`a cover body that fails reports Error until the next cover command`, `a calibrator body that fails reports Error until the next calibrator command`); previously the cover state fell back to a live read. ConformU not re-run.
