### Fixed

- **`run_all_tests.sh` now fails a shrunken test suite, not only an empty one** (`run_all_tests.sh`, issue #592): `ctest --no-tests=error` fails only a run with zero tests, so a vendor target that silently stopped configuring dropped its cases and CI stayed green. After each build the script compares the `ctest -N` count with a per-configuration floor (vendors OFF and ON, AlpacaCore and AlpacaHTTP) kept at the top of the script, and fails naming the configuration, the count found, the floor and where to change it; a configuration with no floor fails too. Documented in `docs/development.md`. Also from issue #593: `scripts/ci_preflight.sh` names a missing Catch2, the clang-tidy configures in `ci.yml` and `ci_preflight.sh` pass `-DALPACACORE_BUILD_TESTS=ON` explicitly, and `AlpacaHTTP/CMakeLists.txt` raises `cmake_minimum_required` to 3.18, which `ctest --no-tests=error` needs.
