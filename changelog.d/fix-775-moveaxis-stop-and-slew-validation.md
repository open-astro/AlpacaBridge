### Breaking changes
- **Synchronous telescope slews are refused** (issue #775, AlpacaHTTP): `SlewToCoordinates`, `SlewToTarget` and `SlewToAltAz` succeeded on 4.x for every telescope driver and now answer `MethodNotImplemented` (0x400); `CanSlew` and `CanSlewAltAz` read false. Clients that call a synchronous slew stop slewing. **After upgrading:** use `SlewToCoordinatesAsync`, `SlewToTargetAsync` or `SlewToAltAzAsync` and poll `Slewing`.
- **SynScan refuses a slew with `Tracking` false** (issue #775, SynScan): the async slews, which are the only ones the router still serves, used to start the GOTO and now raise `InvalidOperation` (0x40B). **After upgrading:** turn `Tracking` on before slewing a SynScan mount.

### Fixed
- **ZWO `MoveAxis(axis, 0)` no longer stops the other axis** (issue #775, ZWO telescope): the stop sends only that axis's directional stops (`:Qe`/`:Qw` or `:Qn`/`:Qs`) instead of `:Q` while the other axis is still jogging (the generic `:Q` is sent once the other axis is idle), so `Slewing` stays true until both axes are stopped (`test_zwo_telescope.cpp`, "MoveAxis stop on one axis leaves the other axis moving").
- **SynScan refuses `SlewToCoordinatesAsync` and `SlewToTargetAsync` with `Tracking` false, and `PulseGuide` during a slew** (issue #775, SynScan): both raise `InvalidOperation` (0x40B); invalid coordinates still raise `InvalidValue` first. The Tracking refusal is a breaking change, see Breaking changes.
- **Bisque guide rates are range-checked** (issue #775, Bisque): `GuideRateRightAscension`/`GuideRateDeclination` outside 0 to 1x sidereal raise `InvalidValue` and leave the stored rate unchanged; before, any finite value was stored.
- **Telescope `CanSlew` and `CanSlewAltAz` read false, and synchronous slews are refused** (issue #775, AlpacaHTTP): the three synchronous slews answer `MethodNotImplemented` (0x400) before any parameter parse, target write or driver call, as ASCOM's slew FAQ asks; the async forms and `CanSlewAsync`/`CanSlewAltAzAsync` are unchanged. See Breaking changes (`test_routing.cpp`, "telescope synchronous slews are MethodNotImplemented (#775)").
