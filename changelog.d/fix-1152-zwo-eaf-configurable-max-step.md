### Added

- **ZWO EAF focuser: configurable Max Step**, ZWO focuser driver and web UI, issue #1152. The new optional `maxStep` setting (1 to 2000000, blank in the web UI = not set) is written to the unit at connect with `EAFSetMaxStep` when it differs from the stored value, and `MaxStep` then reports it; an equal value is not written and an unset one leaves the stored value alone. The EAF stops moves at its stored max step silently, so a driver-only limit would not have held. A `maxStep` above the unit's `EAFStepRange` is clamped to the range (one write of the clamped value, one WARN naming both numbers) and the focuser connects; a unit that stores max step 0 with no `maxStep` set still connects as before (`MaxStep` reads 0, each `Move` is refused, one WARN), issue #1194. Covered by `AlpacaCore/tests/test_zwo_focuser.cpp` (written once, equal not written, unset untouched, above range clamped, stored 0 still connects, unavailable range not clamping) and `AlpacaCore/tests/test_catalog_builtins.cpp` (range and absent-stays-absent).
