- [HTTP] GET /telescope/{device_number}/trackingrates — Returns a collection of supported DriveRates values.
- [HTTP] PUT /telescope/{device_number}/unpark — Unparks the mount.
- [HTTP] GET /telescope/{device_number}/utcdate — Returns the UTC date/time of the telescope's internal clock as a string.
- [HTTP] PUT /telescope/{device_number}/utcdate — Sets the UTC date/time of the telescope's internal clock.
