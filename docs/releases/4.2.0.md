# AlpacaBridge 4.2.0

AlpacaBridge can now update itself from the web UI, so you no longer need a terminal to get the next release. This release also fixes ZWO cameras added by Camera ID, a web UI Restart that could leave the server stopped, and several Sky-Watcher and ZWO mount problems found at the telescope.

## Things that just work better

- **Update AlpacaBridge from the web UI.** The Server Info tab has a new Software Update card. **Check for Updates** tells you whether a newer release is on the OpenAstro apt repository and shows its release notes. **Install Update** installs it through your system's normal apt sources and shows the progress. The service restarts partway through and the page follows it back. Nothing updates on its own, and it only installs when you press the button.
- **The web UI clock tells you when the server's clock is wrong.** Instead of freezing or showing dashes, the header clock reads "clock error" in red. Hover over it, or tap it on a touch screen, to see the reason and the Sync Time fix.

## Fixes worth knowing about

- **ZWO cameras added by Camera ID connect again.** In 4.1.0, every connect of a ZWO camera set up with a Camera ID failed with "Camera ID not specified". Cameras added by index were not affected.
- **Restart in the web UI could stop AlpacaBridge for good.** Depending on timing, a restart ended the service instead of bringing it back, and it stayed down until you started it again. It now comes back.
- **ZWO mounts: guiding could freeze the mount driver.** If PHD2 was guiding while another program connected to the mount, the driver could hang until the service was restarted. Fixed.
- **Sky-Watcher EQ-AL55i Pro: East/West guide pulses landed off target.** Each pulse also gave the RA axis a small unwanted jump. That jump is gone on this board, and other boards are unchanged.
- **Sky-Watcher EQ-AL55i Pro: the log filled with "step period readback" warnings.** This board never reports that value, so the hundreds of warnings a day were noise. They are gone.
- **Sky-Watcher direct: short gotos took at least 8 seconds to finish.** A small move now reports done as soon as the mount stops, which also makes the next goto land more accurately.
- **A very long web address could crash the server.** Such requests are now refused with an error instead.
- **Sync Time from other apps now gets the right reply** when the app sends its request details in the body instead of the address.
- **Behind the scenes:** more automated checks on the documentation and a new code coverage report in the test pipeline.

## Upgrading

```sh
sudo apt update && sudo apt upgrade alpacabridge
```

No configuration changes are needed. This is the last upgrade you need to do from a terminal: from 4.2.0 on, the Software Update card in the web UI can install new releases for you.
