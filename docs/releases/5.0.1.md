# AlpacaBridge 5.0.1

This is a small fix release. It brings back telescope slewing from NINA manual control and TPPA, which 5.0.0 had switched off.

## Fixes worth knowing about

- **Slewing from NINA manual control and TPPA works again.** 5.0.0 told every client that no mount could slew, so these tools refused to move the telescope. The bridge now reports what your mount can actually do, and a mount that can slew accepts the slew commands.
- **Long slews get up to 90 seconds.** The bridge waits up to 90 seconds for the slew to finish. If it takes longer, the client gets an error saying the slew is still running and to watch the Slewing state. The slew is not stopped.
- **Mounts that cannot slew still say so.** They refuse the command right away, as before.
- **Slewing to an Alt/Az position is still not offered.**
- **A correction to the 5.0.0 notes.** They said the mount's slew capability reads false. That is no longer true.

## Upgrading

```
sudo apt update && sudo apt upgrade alpacabridge
```
